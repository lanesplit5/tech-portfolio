Excel Tracking and Dashboard System

I built an Excel-based system to organize information, track activity, and summarize performance. The goal was to make data easier to update, read, and use for decision-making.

  • Purpose: Improve organization and reduce manual tracking issues.
  • Audience: Supervisors, staff, and team leaders.

Python Number Guessing Game

I developed a Python game where users guess a random number and receive feedback based on their answers. This project helped me practice logic, loops, input validation, and user feedback.

  • Purpose: Build programming logic through a simple interactive game.
  • Audience: Beginner users and students learning programming basics.
  • Front End: Command line prompts and user interaction.
  • Back End Thinking: Random number generation, conditions, and loop control.
